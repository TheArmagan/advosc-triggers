Unity package for VRChat avatars

ADVOSC Triggers

Adds SPS sockets, plugs, Touch Zones and contacts to an avatar, then hands ADVOSC the rules that react to them.

Add the VPM listing

This is the listing URL:

https://thearmagan.github.io/advosc-triggers/index.json Add to VCC

The button opens whichever app handles vcc:// links. If nothing opens, add the URL by hand.

Add it by hand

  1. In VCC or ALCOM, open the Packages section and choose Add Repository.
  2. Paste the listing URL above and confirm.
  3. Do the same with VRCFury's listing, https://vcc.vrcfury.com. ADVOSC Triggers depends on VRCFury and can't resolve without it.
  4. Open your avatar project's packages and add ADVOSC Triggers.

Not using a package manager

Each release also has a .unitypackage. Install VRCFury and the VRChat Avatars SDK first, because a .unitypackage can't pull them in.

Status

Version 0.1.0 has been tested in VRChat with contacts and a small test plug and ring. It needs ADVOSC 1.1.0 or newer.
